# Amazon Prime Video Content Analysis

## Project Overview

An end-to-end data analysis project exploring Amazon Prime Video content using **Excel, Power Query, Power BI, and DAX**. The project focuses on data cleaning, transformation, analysis, and dashboard development to identify content distribution and trends.

## Tools & Technologies

* **Excel**
* **Power Query**
* **Power BI**
* **DAX**

## Project Highlights

* Cleaned and transformed the Amazon Prime Video dataset using **Power Query in Excel and Power BI**.
* Prepared the data for analysis by handling missing values, standardizing categories, and transforming fields for reporting.
* Created supporting **country and genre analysis tables** to structure data for analysis.
* Developed **DAX measures** to calculate key metrics and support content distribution and trend analysis.
* Built an interactive **Power BI dashboard** covering **9,668 titles** across content type, genre, country, rating, and release year.

## Key Insights

* Movies account for approximately **81%** of the titles, while TV Shows account for approximately **19%**.
* **Drama** and **Comedy** are among the leading genres by title count.
* The **United States, India, and United Kingdom** are among the countries with the highest title counts in the dataset.
* The dashboard shows a **higher concentration of titles in more recent release years**.
